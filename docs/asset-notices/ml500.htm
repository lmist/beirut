The instruction on installation in game.

For installation you will need program IMGTool v2.0 With its help it is necessary to open a file gta3.img (GTA-SanAndreas\models). Then it is necessary to find and remove old files landstal.dff and landstal.txd (F2> landstal> Enter> Delete> Delete). Now we add new files landstal.dff and landstal.txd (Ctrl+A). In order to prevent mistakes to delete and add files it is necessary on one. When you have executed these actions, we close IMGTool.

Now it is necessary to make adjustments of the machine in three files (GTA-SanAndreas\data) which open by means of the standard program "Notebook". In each of these files it is necessary to replace a line which begins the name of model. Correct adjustments of the machine are below resulted.

 

handling.cfg

LANDSTAL 2100.0 6000.0 3.0 0.0 0.2 -0.30 75 0.60 0.80 0.51 5 235.0 27.7 15 4 P 10.0 0.53 1 32.0 1.50 0.13 0.0 0.18 -0.12 0.5 0.5 0.44 0.30 95000 00002020 00400004 1 2 0

vehicles.ide

400, landstal, landstal, car, LANDSTAL, LANDSTK, null, normal, 10, 0, 0, -1, 0.8, 0.8, 0

carcols.dat

landstal, 0,0, 4,4, 13,13, 25,25, 41,41, 43,43, 53,53, 119,119

carmods.dat

landstal, nto_b_l, nto_b_s, nto_b_tw

If all of you have correctly made, there will be no various bugs and the car will look as on a screenshot.
