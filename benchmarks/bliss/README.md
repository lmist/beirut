# Bliss Street verification

The renderer was checked at the eastern arrival, AUB Main Gate, middle blocks,
and western bend. Runtime snapshots and rendered views are saved here. These
are scene checks, not a controlled 30-second performance benchmark. Initial
warm-up frames should not be compared with steady-state frame samples.

The final build uses 27 photo-reviewed facade buildings and five complete
replacement buildings, plus the new AUB Main Gate, campus boundary and canopy.
Remaining faces preserve the existing photographic fallback. See
`docs/bliss-street.md` for evidence counts and reconstruction limits.

The full JavaScript suite passes 105 checks; the production build succeeds.
The build retains Vite's existing advisory about large bundles.
